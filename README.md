# 2D Platformer Unity

![2D Platformer Gameplay](Screenshots/gameplay.png)

A 2D action platformer developed with Unity and C#, focused on gameplay programming, combat, enemy behaviour and interactive systems.

[![Play Game](https://img.shields.io/badge/Play%20Game-itch.io-orange)](https://cerverus.itch.io/2dplatformer)

## About the Project

2D Platformer is a solo game project developed with Unity and C#.

The project was developed to demonstrate gameplay programming, game design and the implementation of interactive systems.

### Features

• Player movement and platforming mechanics
• Basic combat system
• Enemy interactions
• Player health system
• Level design and gameplay mechanics
• Gameplay system integration

### My Role

I was responsible for the programming and game design of the project.

I implemented the gameplay systems in Unity using C#, designed the gameplay mechanics and levels, and integrated the different assets and systems into the final playable experience.

The environment and enemy artwork were sourced from external asset repositories and integrated into the project.

## Technical Highlights

### Player Controller

Implemented the player movement and platforming system in Unity using C#, including movement, jumping and interaction with the platform environment.

### Combat System

Implemented a basic combat system that allows the player to interact with and damage enemies during gameplay.

### Enemy Systems

Implemented enemy behaviour and gameplay interactions using C# scripts, integrating enemies into the player's combat and level systems.

### Gameplay Systems

Developed and integrated gameplay systems including player health, movement, combat and interactions between gameplay elements.

### Game Design

Designed the gameplay mechanics and levels, focusing on player movement, platforming challenges and combat encounters.
